# Major Project

Project workspace for data preprocessing, feature engineering, supervised modeling, anomaly detection, hybrid detection, and evaluation.

## Structure

- `data/raw/`: source datasets
- `data/processed/`: cleaned and transformed datasets
- `models/`: saved model artifacts
- `results/graphs/`: generated visualizations
- `results/reports/`: generated reports
- `notebooks/`: exploratory analysis
- `src/`: reusable project modules
- `main.py`: pipeline entry point

## Run

```bash
python main.py
```
